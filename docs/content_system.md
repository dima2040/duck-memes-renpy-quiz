# Sprint 2 Content System Notes

Sprint 2 оставляет игру quiz-first и намеренно небольшой. Повторяющаяся логика
вопросов, меню и счёта теперь живёт в общем flow в `game/script.rpy`, а текст
вопросов, варианты, правильность и реакции лежат в `game/quiz_content.rpy`.

## Добавить Или Изменить Вопрос

1. Откройте `game/quiz_content.rpy`.
2. Найдите нужный раунд внутри `QUIZ_ROUNDS`.
3. Добавьте или измените один словарь в списке `questions`.
4. Задайте стабильный `id`, `prompt` и список `answers`.
5. Отметьте ровно один ответ через `"correct": True`.
6. Запишите feedback-реплики в `response` как пары speaker/text:

```renpy
{
    "id": "r1_q4",
    "prompt": "Вопрос 4. Новый утверждённый вопрос?",
    "answers": [
        {
            "text": "Правильный вариант",
            "correct": True,
            "response": [
                ("mbk", "МужикБыкКорова подтверждает канон."),
            ],
        },
        {
            "text": "Неправильный вариант",
            "correct": False,
            "response": [
                ("neo", "Неофиты ошиблись."),
                ("mbk", "Короткая реакция объясняет ошибку."),
            ],
        },
    ],
}
```

Доступные speaker ids:

- `mbk`: МужикБыкКорова.
- `neo`: Неофиты.
- `p`: Покляйкомэн.

## Добавить Раунд

1. Добавьте новый словарь раунда в `QUIZ_ROUNDS` в `game/quiz_content.rpy`.
2. Добавьте короткий hand-authored intro/interlude label в `game/script.rpy`.
3. Из этого label вызовите `play_quiz_round(quiz_round_by_id("new_round_id"))`.
4. Проверьте финальный порог `QUIZ_LEGEND_THRESHOLD`: для текущих 9 вопросов
   победа засчитывается при 7-9 правильных ответах.

VN-связки остаются в `game/script.rpy`, потому что их удобнее писать и править
как обычные Ren'Py-сцены. Квиз-контент вынесен в данные, потому что именно там
в Sprint 1 было больше всего повторения и будущего content churn.
