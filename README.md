# Duck Memes Ren'Py Quiz

Школьная Ren'Py-викторина из шести вопросов про Кля, Ква, Кря, Покря, Кляйко, Покляйко, Покляйкомэна, Крякай и Утю.

## Запуск

1. Создайте или откройте проект в Ren'Py Launcher.
2. Поместите содержимое папки `game/` в папку `game` своего проекта.
3. Добавьте изображения или определения для фонов и спрайтов, упомянутых в `game/script.rpy`.

## Публикация на GitHub

Используйте `publish_renpy_project.sh` в Bash/Git Bash после установки Git и GitHub CLI.
