# Duck Memes Ren'Py Quiz

Школьная Ren'Py-викторина про абсурдный мем-канон. Sprint 2 сохраняет
10-минутный quiz-first vertical slice из Sprint 1: 3 раунда по 3 вопроса,
короткие VN-прослойки между раундами и финальное признание игрока восходящей
школьной легендой при успешном результате. Повторяющаяся квиз-логика вынесена
в общий flow, а вопросы и реакции теперь лежат в отдельной content-структуре.

Контент вопросов пока использует только прототипные seed-слова из Sprint 0
(`Кля`, `Ква`, `Кря`, `Покря`, `Покляйко`, `Покляйкомэн`, `Утя`) и не является
финальным утверждённым мем-каноном.

## Проверка Sprint 2

- Проект появляется и запускается в Ren'Py Launcher.
- Игрок проходит 3 квиз-раунда: `База`, `Кодекс`, `Испытание легенды`.
- В каждом раунде есть 3 вопроса, всего 9 вопросов.
- Между раундами есть короткие VN-сцены с реакцией неофитов и эскалацией.
- МужикБыкКорова считывается как главный знаток мемов, судья и наставник.
- Неофиты считываются как безымянная толпа одноклассников с неправильными шутками.
- Неверные ответы дают короткую реакцию, увеличивают счётчик ошибок и не ломают flow.
- Итог 7+ из 9 ведёт к финалу с признанием игрока восходящей легендой школы.
- Итог ниже 7 ведёт в game over с возможностью retry.
- Нет ошибок missing image/font/config.

## Редактирование квиз-контента

- Вопросы, варианты ответов, правильность и реакции лежат в `game/quiz_content.rpy`.
- Общая логика показа вопроса, начисления score и подсчёта mistakes находится в
  `game/script.rpy` в labels `play_quiz_round` и `play_quiz_question`.
- Короткие VN-сцены между раундами остаются в `game/script.rpy`, чтобы их было
  удобно писать как обычный Ren'Py-сценарий.
- Подробная заметка для добавления вопроса или раунда: `docs/content_system.md`.

## Временные ассеты

Файлы в `game/images/` остаются placeholder-артом. Для Sprint 2
`teacher_funny.png` также используется как временный placeholder для
МужикБыкКорова через алиас `mbk_placeholder`. Финальный арт, звук и
презентационный polish относятся к последующим спринтам.
